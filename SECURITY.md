# Security policy

## Report a vulnerability

Report security problems privately through a GitHub security advisory:
https://github.com/spdotdev/manual/security/advisories/new

Do not open a public issue or pull request for a suspected vulnerability. Include the affected version or commit,
the file or step involved, how to reproduce it, and what you think the impact is.

## Scope

In scope: the skill instructions (`SKILL.md` and references), any scripts in this repository, and the CI workflows.
Out of scope: problems in the AI host you run the skill in, and in third-party tools the skill calls.

## What to expect

A first reply within 7 days. A fix or a written decision once the report is confirmed.
